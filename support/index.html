    Support¶

    Support AVLite¶

    AVLite is free and open source. GitHub already hosts the docs and packages. If it helped your research, teaching, or robot, a donation buys time to run tests, review and test plugins, and add features.

    Built in the UAE · من الإمارات

    ادعم أفيلايت. مشروع مفتوح المصدر من الإمارات. إن ساعدك في بحثك أو تدريسك أو روبوتك، فإن دعمك يبقينا مستمرين: يموّل تشغيل الاختبارات، ومراجعة الإضافات واختبارها، وإضافة ميزات جديدة.
